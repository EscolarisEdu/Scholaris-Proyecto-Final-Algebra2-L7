Paso 2 · Ejemplo de guía

Observa una bitácora parecida

No copies este ejemplo: usa polinomios diferentes a los de tu proyecto. Solo sirve para mostrar cómo organizar el procedimiento.
Ejemplo: (x+1)(x²+2)
1. Distribuye x: x(x²)+x(2)=x³+2x
2. Distribuye 1: 1(x²)+1(2)=x²+2
3. Reúne los cuatro productos parciales: x³+2x+x²+2
4. Ordena: x³+x²+2x+2
5. El producto tiene grado 3 porque 1+2=3.
Lee una línea a la vez y observa cómo el orden hace visible cada producto.
